# Support

| Need | Where |
|---|---|
| How do I use a template? | The technology's `README.md` (every technology directory has one) |
| Something is broken | Open an issue using the bug template; include the output of `python scripts/pib.py run <stage> -v` |
| Feature / new technology | Open an issue using the feature template; check [ROADMAP.md](ROADMAP.md) first |
| Security issue | **Never** a public issue - follow [SECURITY.md](SECURITY.md) |
| Contribution workflow | [CONTRIBUTING.md](CONTRIBUTING.md) |

This is a reference repository; templates require environment-specific review before production use
(see the classification in each README and in [reports/known-limitations.md](reports/known-limitations.md)).
