# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. All contributors and maintainers are expected to follow it in every project space
(issues, pull requests, reviews, chat, and events).

## Summary of expectations

- Be respectful and assume good intent; critique ideas and code, never people.
- Give actionable, specific review feedback; accept feedback gracefully.
- No harassment, discrimination, personal attacks, or publishing others' private information.
- Never post secrets, credentials, or personal data in issues or pull requests (see [SECURITY.md](SECURITY.md)).

## Reporting

Report unacceptable behaviour privately to the maintainers listed in
[`.github/CODEOWNERS`](.github/CODEOWNERS) (replace the placeholder team with real contacts when adopting
this repository). Reports are handled confidentially. Enforcement follows the
[Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
